Custom database tables are a powerful WordPress plugin pattern, but easy to teach poorly. The WordPress Training Team needed practical, accurate material for developers learning how to create, migrate, and query tables without fighting core conventions.

I authored and iterated on **Module 07 lessons** in the public [`learn-wp-content`](https://github.com/wptrainingteam/learn-wp-content) repository—including the foundational “Creating and Managing Custom Tables” lesson ([PR #11](https://github.com/wptrainingteam/learn-wp-content/pull/11)), follow-up content on interacting with custom tables ([PR #16](https://github.com/wptrainingteam/learn-wp-content/pull/16)), and supporting audio/video code examples ([PR #17](https://github.com/wptrainingteam/learn-wp-content/pull/17)).

Contributing to Learn WordPress lets me pay forward the documentation that helped me grow as a plugin engineer—and keeps Purple Turtle Creative visible in the broader open-source ecosystem.
