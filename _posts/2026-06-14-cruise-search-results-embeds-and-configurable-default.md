TopCruiseDeals still depends on a partner itinerary search experience while owned sailing content comes online. Marketing needed that search visible on key templates—with sensible calls to action—and the ability to change which embed variant is the site default as campaigns evolve.

I shipped theme updates ([PR #4](https://github.com/PurpleTurtleCreative/topcruisedeals/pull/4), [PR #5](https://github.com/PurpleTurtleCreative/topcruisedeals/pull/5)) to place search results embeds on the right pages, refine CTA placement, and expose a **configurable default embed** so the team can switch behavior from WordPress rather than code changes ([commit d14a6367](https://github.com/PurpleTurtleCreative/topcruisedeals/commit/d14a6367848f3f88502e0c05d51bfa231705ae83)).

Visitors get a consistent path into cruise search while the business keeps control of presentation as the broader itinerary program matures.
